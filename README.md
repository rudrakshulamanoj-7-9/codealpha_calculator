# 🧮 Simple Calculator

A beginner‑friendly **HTML, CSS, and JavaScript** project that performs basic arithmetic operations.  
It features a clean UI with buttons for digits, operators, and utility functions like clear and delete.

---

## 🚀 Features
- Responsive calculator layout
- Supports addition, subtraction, multiplication, and division
- Clear button to reset input
- Delete button to remove last character
- Decimal point support
- Smooth and interactive design

---

## 📂 Project Structure
calculator/
